Enhanced Artifacts

Software Engineering & Design

For the Software Engineering and Design category, I selected a 3D rendering project originally developed in C++ and OpenGL. This artifact showcases full control over the graphics pipeline through custom GLSL shaders, including a vertex shader responsible for matrix‑driven coordinate manipulation and a fragment shader that computes realistic surface textures and Phong lighting across directional, point, and spot light sources.

I chose this artifact because it represents a technically challenging and personally meaningful part of my programming journey. Enhancing it allowed me to demonstrate modular software engineering, shader architecture improvements, and rendering pipeline refinement. The project’s complexity made it an ideal candidate for showcasing advanced engineering skills and thoughtful system design.

Algorithms & Data Structures

For the Algorithms and Data Structures category, I selected my Weight Tracking App, originally built as a mobile application that allowed users to log daily weight entries. While functional, the initial version did not perform deeper analysis or provide meaningful predictions. Enhancing this artifact allowed me to transform it from a basic CRUD application into an intelligent system capable of analyzing patterns and forecasting future values.

I implemented a predictive trend model using a multi‑step algorithm involving data windowing, smoothing, linear regression, and safeguard logic. This enhancement demonstrates algorithmic reasoning, responsible data processing, and thoughtful design choices. It also highlights my ability to integrate algorithms with UI components, database logic, and custom rendering code.

Databases

For the Databases category, I selected the Weight Tracking App’s original persistence layer, which relied on raw SQLite queries. While functional, the original implementation lacked structure, compile‑time validation, and modern best practices. Enhancing this artifact required migrating the entire data layer to Room, Android’s object‑relational mapping framework.

This enhancement demonstrates my ability to redesign and modernize a database system using industry‑standard tools. I created entity classes, DAO interfaces, a Room database, and integrated Kotlin coroutines to ensure safe background execution. I also resolved architectural issues, improved UI consistency, and strengthened permission handling. Together, these improvements significantly enhanced the app’s reliability, maintainability, and security.
