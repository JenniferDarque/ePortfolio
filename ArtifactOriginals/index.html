This page provides access to the original, unmodified versions of all three Capstone artifacts. These files represent the starting point before enhancements were completed for the Capstone Project.

Original Software Engineering & Design Artifact

The original version of the 3D rendering project created in C++ and OpenGL. This includes the original shaders, rendering pipeline, and scene files prior to the Blinn‑Phong lighting upgrade and architectural refactoring.

Original Algorithms & Data Structures Artifact

The original version of the Weight Tracking App before predictive trend analysis was implemented. This version includes basic CRUD operations, UI components, and the initial data handling logic.

Original Databases Artifact

The original persistence layer of the Weight Tracking App before migrating from raw SQLite queries to Room. This version includes the original database logic, UI interactions, and data storage methods.
